# Garage Golf Enclosure — 3D model

Interactive 3-D viewer for a modular, freestanding garage golf impact-screen enclosure.

Open the live page: **https://omarsimpson24.github.io/golf-enclosure-3d/**

- Drag or swipe to rotate, pinch or scroll to zoom
- Tap a part for its number, specs, quantity, and estimated cost
- Use the buttons for top, side, and front views, or to explode the parts

Cost figures are rough 2026 US retail estimates, not quotes. The repository is a static HTML page only; it does not contain personal information.
